A single funny line for the make.fun "One Line, One Laugh" bounty: a GPS that has given up on its driver.

## The entry

> My GPS has said 'recalculating' so often it now just sighs and asks if I've considered staying home forever.

## How to run

```sh
python3 main.py
```

This writes the line to `entry.txt` in the directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`), with a trailing newline.
